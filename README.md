# tree-sitter-wyrm

[Tree-sitter](https://tree-sitter.github.io/) grammar for the [Wyrm](https://wyrm-lang.com)
language (`*.wy`, `*.wyrm`).

The language definition it follows is `doc/grammar.md` in the
[wyrm](https://codeberg.org/wyrm-lang/wyrm) repository. This grammar is for highlighting and
navigation, so it is deliberately a little more permissive than the real parser.

Used by [wyrm-gram](https://github.com/Wyrm-Language/wyrm-gram), the Gram (Zed fork)
extension.

## Layout

| Path | What it is |
| --- | --- |
| `grammar.js` | the grammar |
| `src/scanner.c` | external scanner: the offside rule (`_newline`, `_indent`, `_dedent`) |
| `src/parser.c`, `src/*.json`, `src/tree_sitter/` | generated by `tree-sitter generate`, committed |
| `queries/highlights.scm` | highlights with tree-sitter's standard capture names |
| `test/corpus/` | `tree-sitter test` cases |
| `bindings/` and the package files | generated by `tree-sitter init` (C, Go, Node, Python, Rust, Swift) |

Editors keep their own query variants, because capture names differ between them; Gram's
are in wyrm-gram's `languages/wyrm/`.

## Development

```sh
npm install
(cd node_modules/tree-sitter-cli && node install.js)   # fetch the tree-sitter binary
npx tree-sitter generate
npx tree-sitter test
```

`src/parser.c` and friends are generated **and committed**, because editors compile the
grammar from the repository. Regenerate and commit them after every change to `grammar.js`;
CI fails if they are stale.

Layout lives in `src/scanner.c`. A newline is only a statement separator where the grammar
can accept one, so line breaks inside `( )` and `[ ]` are whitespace, as in the real
tokenizer.

Known gaps: a statement directly after a `{ ... }` block on the same line (no `;`) recovers
with a MISSING node.

## Using it from an editor

The grammar is at the repository root, so no subdirectory setting is needed. Pin a commit:

- **Gram / Zed** (`extension.toml`): `[grammars.wyrm]` with `repository` and `rev`.
- **Helix** (`languages.toml`): `[[grammar]] name = "wyrm"`, `source = { git = "…", rev = "…" }`.
- **Neovim** (nvim-treesitter): a parser config with `install_info = { url = "…", revision = "…" }`.
